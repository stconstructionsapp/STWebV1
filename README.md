# ST Constructions Group - Production Node.js + Express Web Application

Official website and corporate portal for **ST Constructions Group** (`stconstructionsgroup.com`), showcasing:
1. **Real Estate Development** (Narayani Villa 120-Duplex Township on Deva Road near Kisan Path, Lucknow)
2. **Real Estate Construction** (Turnkey home building on private plots across Lucknow)
3. **Real Estate Mandate** (Exclusive sales mandate and project marketing partner for developers)

---

## Production Deployment on Hostinger Node.js Hosting

This application is built for direct deployment on **Hostinger Node.js Web Hosting** using the **Express Framework Preset** and **Node.js 22.x**.

### Hostinger Deployment Settings

| Setting | Value to Use |
| :--- | :--- |
| **Deployment Platform** | Hostinger Node.js Hosting / Web Application |
| **Framework Preset** | `Express` |
| **Node.js Version** | `22.x` (or `>=20.0.0`) |
| **Repository Branch** | `main` |
| **Root Directory** | `/` |
| **Entry File** | `server.js` (or `app.js`) |
| **Build Command** | `npm run build` |
| **Start Command** | `npm start` |
| **Output Directory** | *Leave Empty* (Express serves the app dynamically) |

## Backend API Endpoints

- `GET /api/health` — Returns JSON server health, uptime, and adapter status.
- `POST /api/enquiries` — Receives customer visit & enquiry submissions with honeypot spam protection, rate limiting, and optional CRM webhook forwarding.
- `GET /*` — Serves the compiled React Single Page Application (`dist/index.html`) with client-side SPA routing fallback.
