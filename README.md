# ST Constructions Group - Node.js + Express Web Application

Official website and corporate portal for **ST Constructions Group** (`stconstructionsgroup.com`), showcasing:
1. **Real Estate Development** — Narayani Villa 120-Duplex Township on Deva Road near Kisan Path, Lucknow
2. **Real Estate Construction** — Turnkey residential home building on private plots across Lucknow
3. **Real Estate Mandate** — Exclusive sales mandate and project marketing partner for developers

---

## Architecture Overview

- **Frontend:** React 19 + TypeScript + Vite 8 + Tailwind CSS v4 (`src/`)
- **Backend:** Modular TypeScript Express server (`server.ts` + `server/app.ts` + `server/api.ts`), bundled cleanly to `server.js` at the project root during `npm run build`
  - Serves REST endpoints (`/health`, `/api/health`, `/api/enquiries`) with validation, honeypot spam protection, rate limiting, and server-side Web3Forms / CRM webhook forwarding
  - Serves the compiled React SPA from `dist/` with SPA client-side routing fallback

## Environment Variables

Configure these in **Hostinger hPanel -> Node.js Web App -> Environment Variables** (see `.env.example`):

| Variable | Required | Description |
| :--- | :---: | :--- |
| `PORT` | Auto / Optional | Assigned automatically by Hostinger (`process.env.PORT`). Falls back to `3000`. |
| `HOST` | Optional | Bind address (`0.0.0.0` by default). |
| `NODE_ENV` | Recommended | Set to `production` on Hostinger. |
| `APP_URL` | Recommended | Public site URL, e.g. `https://stconstructionsgroup.com`. |
| `WEB3FORMS_ACCESS_KEY` | Optional | Server-side Web3Forms access key for email lead notifications. |
| `CRM_WEBHOOK_URL` | Optional | External HTTPS webhook URL to forward `/api/enquiries` leads to your CRM. |

## Local Verification Commands

```bash
# 1. Install dependencies cleanly
npm install

# 2. Type-check frontend and server TypeScript
npm run lint

# 3. Start unified Express + Vite dev server on http://0.0.0.0:3000
npm run dev

# 4. Build production frontend (dist/) and bundle root entry (server.js)
npm run build

# 5. Start production Express server on http://0.0.0.0:3000
npm start

# 6. Verify health endpoints
curl http://localhost:3000/health
curl http://localhost:3000/api/health
```
